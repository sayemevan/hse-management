## Consequences for the plan

- **Billing and tenant onboarding enter Phase 1.** That means a registration flow, subdomain allocation, plans, subscription status, and a System Owner verification queue. The [sprint plan](../05_SPRINT_PLAN.md) needs a new sprint for this before Company Management.
- **Subdomain routing** must resolve the tenant from the host name in both the web app and the API (Cloudflare wildcard DNS and custom-hostname support later).
- **Offline capture** (D-11) requires a service worker, a local store (IndexedDB), a sync queue with conflict rules, and idempotent API writes. It affects the Inspection and Safety Event sprints.
- **Arabic in Phase 1** (D-14) means i18n and RTL must be in place before the first screen, plus Arabic text search (Q-35).
- **Short status lists** (D-12) drop states that the Product Book workflows reference ("Under Review", "Verification", "Suspended" permit). The approval steps are still required, so they will be modelled as workflow steps or approval records rather than statuses. This needs confirmation when those stories are specified.
